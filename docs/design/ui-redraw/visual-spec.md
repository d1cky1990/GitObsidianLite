# 视觉规范：纸页感（浅色 / 深色）

> **状态**：2026-11-03 定稿。沿「原型：三个视觉方向各出一张样张」选定的 **A · 纸页感** 展开。
>
> **读者**：负责高保真原型与前端实现的人。本文给出可以直接翻成 CSS 的值，不再依赖“暖一点”“轻一点”这类感觉。
>
> **范围**：只规定外观、尺寸、动效与主题落地顺序。交互与文案以同目录的 `design-brief.md` 为准；正文渲染结构与冲突合并内部结构不改。

---

## 1. 一眼认出这套设计

- **正文像纸，工具像铅笔痕迹。** 页面用暖纸色；正文用衬线字；按钮、树、设置用系统无衬线字。层级先靠字与留白，细线只负责分隔。
- **不做一屏卡片。** 正文、顶栏、侧栏都不是浮起来的卡片。只有真正浮在页面上的弹窗、操作表、气泡与提示条使用阴影。
- **选中与正在读不是一回事。** 选中的文件夹用左侧短竖线；正在读的笔记用浅底与强调色文字。两者落在同一行时，两种记号都保留。
- **暗色是另一张纸，不是浅色的负片。** 暗色用暖炭灰底、柔米白字、低饱和棕金强调色；图片、代码、表格、声明区分别处理，不做 `invert()`。

### 2.2 使用规则

1. **文字不放在未经列出的颜色组合上。** 新增组合时必须补测对比度。
2. 正文 / 次要文字 / 可读的占位文字，正常字号对比度至少 **4.5:1**；大号粗体至少 **3:1**。控件边界与焦点环至少 **3:1**。
3. `--color-text-faint` 已满足正常文字对比度，不能再用 `opacity` 把它继续变淡。`--color-disabled` 只用于非文字；置灰但仍可按的文件动作使用 `--color-text-faint`，因为它还必须读得清。
4. 状态不能只靠颜色表达：成功 / 警告 / 危险都要有文字或图标。普通“正在确认位置”用中性色，**不用 warning，更不用 danger**。
5. 链接默认使用 `--color-accent`，保留下划线；悬停换色不是唯一反馈。正文之外的双链也照此处理。
6. 主按钮每个动作区最多一个实心按钮。删除确认使用危险色文字与边框，不用整块刺眼的红底。

## 3. 主题如何落地：第一帧就不能白

### 3.1 CSS 入口

```css
:root {
  color-scheme: light;
  /* 此处放 §2.1 的浅色 token。 */
}

:root[data-theme="dark"] {
  color-scheme: dark;
  /* 此处放 §2.1 的深色 token。 */
}

html,
body {
  margin: 0;
  min-height: 100%;
  background: var(--color-page);
  color: var(--color-text);
}

::selection {
  background: var(--color-selection);
  color: var(--color-text);
}

:focus-visible {
  outline: 2px solid var(--color-focus);
  outline-offset: 2px;
}

[hidden] {
  display: none !important;
}
```

主题的存储值为 `light` / `dark` / `system`，缺省为 `system`。最终 `data-theme` 只写解析后的 `light` 或 `dark`，让两套 token 只有一处判断。

### 3.2 必须按这个顺序

1. 在页面模板的 `<head>` 里、**主样式表之前**，放一段不依赖主程序的内联代码。
2. 这段代码只读本机主题记录；没有记录时读系统外观。随即在 `<html>` 上写好 `data-theme` 与 `color-scheme`。
3. 再加载样式。`html` 与 `body` 的第一帧都使用 `--color-page`，浏览器原生表单也跟随同一个 `color-scheme`。
4. 主程序启动后再读同一份记录；若值为 `system`，监听系统外观变化。两处留镜像注释，任何一处改存储格式，另一处必须同改。
5. 用户在设置里切换时，直接改 `data-theme` 并写记录；不刷新页面，不给全局颜色加过渡。

```html
<meta name="color-scheme" content="light dark">
<script>
  (() => {
    let preference = "system";
    try {
      preference = localStorage.getItem("gitobsidianlite.theme") || "system";
    } catch (_) {}
    const dark = preference === "dark" ||
      (preference === "system" && matchMedia("(prefers-color-scheme: dark)").matches);
    document.documentElement.dataset.theme = dark ? "dark" : "light";
    document.documentElement.style.colorScheme = dark ? "dark" : "light";
  })();
</script>
<!-- 主样式表放在这段代码之后。 -->
```

**验收方法**：本机存为深色后，从浏览器真正刷新页面，并覆盖解锁框会出现的启动路径；任何一帧都不能先出现白底。只在应用内切到深色不算验过。

## 4. 字体、字号与行宽

### 4.1 字体栈

不下载字体，不引 CDN。三款字体都使用本机已有字体。

```css
:root {
  --font-ui: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
    "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
  --font-reading: "Songti SC", "STSong", "Noto Serif CJK SC",
    "Source Han Serif SC", "SimSun", serif;
  --font-mono: ui-monospace, "SFMono-Regular", Consolas,
    "Liberation Mono", monospace;
}
```

- 正文、文章标题、侧栏标题用 `--font-reading`。
- 树、搜索、设置、按钮、提示、元信息用 `--font-ui`。
- 代码与 Tasks 中的代码记号用 `--font-mono`。
- 编辑态输入区用 `--font-ui`，避免中文等宽字体回退后字形参差。

### 4.2 字号阶梯

| 用途 | 手机 | 宽屏 | 字重 / 行高 |
|---|---:|---:|---|
| 正文阅读 | 17px | 18px | 400 / 1.85 |
| 文章 H1 | 28px | 32px | 600 / 1.35 |
| 文章 H2 | 21px | 23px | 600 / 1.45 |
| 文章 H3 | 18px | 20px | 600 / 1.5 |
| 顶栏篇名 | 15px | 16px | 500 / 1.4 |
| 侧栏标题、弹窗标题 | 18px | 20px | 600 / 1.4 |
| 普通按钮、设置项 | 15px | 15px | 500 / 1.5 |
| 树行、搜索结果 | 14px | 14px | 400 / 1.5；文件夹 600 |
| 表单输入 | **16px** | 15px | 400 / 1.5 |
| 编辑态输入区 | 16px | 16px | 400 / 1.75 |
| 标签、短辅助说明 | 13px | 13px | 400 / 20px |
| 代码块、行内代码 | 14px | 14px | 400 / 1.65 |
| 日期、父目录、版本号等元信息 | 12px | 12px | 400 / 18px |

**手机下限**：任何文字不得小于 12px；12px 只用于非关键元信息。按钮、输入、失败原因、状态说明不得小于 14px。手机表单输入固定 16px，避免 iOS 聚焦时自动放大页面。

### 4.3 正文版心

```css
.article {
  width: 100%;
  max-width: 784px;
  margin-inline: auto;
  padding: 20px 22px 128px;
  font-family: var(--font-reading);
}

@media (min-width: 900px) {
  .article { padding: 32px 32px 128px; }
}

@media (max-width: 359px) {
  .article { padding-inline: 16px; }
}
```

宽屏下 784px 减去左右各 32px，**实际文字行宽上限 720px**，不比今天的版心窄。手机上随屏宽收缩；不为了“凑每行字数”把正文缩到 17px 以下。

- 段落：`margin: 0 0 20px`。
- H1：`margin: 0 0 20px`。
- H2：`margin: 32px 0 12px; padding-top: 20px; border-top: 1px solid var(--color-border)`。
- H3：`margin: 28px 0 12px`。
- 列表与引用沿用正文 17 / 18px，不另造一套小字。

## 5. 间距、尺寸与骨架

### 5.1 间距刻度

只用这一组，不在组件里随手取 5px、7px、10px。

| Token | 值 | 常见用途 |
|---|---:|---|
| `--space-0` | `0` | 无间距 |
| `--space-1` | `4px` | 图标与小字之间、相邻控件最小间隔 |
| `--space-2` | `8px` | 树行图标与名字、按钮组 |
| `--space-3` | `12px` | 树行左右、声明区内缩、小面内边距 |
| `--space-4` | `16px` | 设置分组、输入框与说明 |
| `--space-5` | `20px` | 弹窗内边距、段落下距 |
| `--space-6` | `24px` | 正文与声明区间距、大分组 |
| `--space-8` | `32px` | 宽屏正文左右、H2 上距 |
| `--space-10` | `40px` | 空状态主块上下 |
| `--space-12` | `48px` | 大区间隔 |
| `--space-16` | `64px` | 只用于空状态顶部留白，不用于普通段落 |

### 5.2 固定尺寸

| 部位 | 规范 |
|---|---|
| 独立可点区 | 最小 **44×44px**；主要行动作高 48px |
| 树行 | 高 44px；左内边距 12px + 每层 14px；右内边距 12px |
| 树缩进 | 第 1～4 层分别 12 / 26 / 40 / 54px；第 5 层起固定 54px |
| 树图标 | 文件夹 / 笔记 18px；展开箭头 12px；图标与名字间隔 8px |
| 顶栏 | 最小高 56px，另加安全区；按钮 44×44px |
| 侧栏 · 手机 | 宽 `75vw`，390px 屏为 292.5px；高度跟随可见视口 |
| 侧栏 · 宽屏 | 固定 **304px**，不随窗口继续变宽 |
| 搜索框 | 高 44px；内部左右 12px；手机输入字 16px |
| 搜索 / 新建 / 设置入口 | 同一固定头部；新建与设置各 44×44px；间隔 4px |
| 搜索结果行 | 最小 52px；需要父目录时 64px |
| 最近打开条目 | 最小 64px；名字 15px，父目录 12px |
| 标签胶囊 | 高 22px；左右 7px；圆角 999px；标签间 4px |
| 勾选框 | 看见的部分 18×18px；外层命中区 44×44px |
| 普通弹窗 | 宽 `min(420px, calc(100vw - 32px))`；内边距 20px |
| 底部操作表 | 宽度不超过 480px；动作行 48px；底部加安全区 |
| 编辑动作区 | 最小高 56px + 底部安全区；保存 / 取消始终可见 |
| 全局提示条 | 高 32～36px；左右内边距 16px、上下 8px；宽上限 80vw；离可见视口底 80px；13px 字 |

第 5 层及更深不再加缩进，在行首图标前加一个 **6×6px 的折角层级记号**：左边与下边各 1px，颜色 `--color-text-faint`，与后图标间隔 4px。它不是文件夹图标，也不响应点击。

### 5.3 布局细节

- 侧栏头部固定，树 / 结果 / 设置各自滚动；三块内容切换时**搜索输入框节点不动**。
- 有搜索词时，新建按钮用 `hidden` 隐藏；不要用透明度留个看不见但能按的按钮。
- 手机侧栏盖住正文；遮罩只覆盖露出的正文区，点击区至少为那 1/4 屏宽。
- 宽屏正文在侧栏之外的剩余区域居中；侧栏收起后仍保持 720px 文字行宽上限。
- 键盘弹起时，布局读取可见视口。编辑动作区随可见视口移动，不能固定在已被键盘遮住的布局底部。
- 弹窗与操作表的最大高度为“可见视口高度 − 32px”，内容超出时内部滚动，标题与主动作不滚走。

## 6. 圆角、阴影与层级

### 6.1 圆角

| Token | 值 | 用途 |
|---|---:|---|
| `--radius-xs` | `3px` | 透明小按钮、行内代码 |

### 6.3 层级

| 层 | z-index | 说明 |
|---|---:|---|
| 正文与宽屏侧栏 | 0～1 | 正常文档流 |
| 吸顶顶栏 / 侧栏固定头 | 10 | 不压浮层 |

## 7. 组件外观

### 7.1 树与搜索结果

- 默认行：透明底、`--color-text`；图标用 `--color-text-secondary`。
- 悬停：`--color-hover`；按下：`--color-pressed`。按下不缩放、不位移。
- 选中的文件夹：`--color-selected` 底 + 左侧 `2px` 的 `--color-accent` 内嵌竖线。
- 正在读的笔记：`--color-current` 底、`--color-accent` 字，字重 600；不要再用左侧竖线。
- 同一行同时符合两者：当前笔记底与字 + 选中竖线，两个事实都看得见。
- 宽屏行尾「⋯」只在行悬停或键盘聚焦时出现，命中区 44×44px；窄屏不预留这个按钮的位置。
- 长名字区域单独横向滚动，行尾至少留 12px 空白；计数不压名字。
- 加载与失败占据同一个内容容器，切换时不改变侧栏头部和输入框。加载用静态文字与两条固定高度的浅色占位，不用闪烁动画，也不画一棵空树。

### 7.2 按钮、输入与选择控件

- 透明图标按钮：默认透明，悬停 `--color-hover`，按下 `--color-pressed`；图标颜色 `--color-text`。
- 主按钮：`--color-accent` 底、`--color-on-accent` 字，最小高 44px，左右内边距 16px。
- 次按钮：透明底、`--color-border-strong` 边、`--color-text` 字。
- 危险按钮：透明底、`--color-danger` 字与边；确认弹窗里不用大面积红底。
- 输入框：`--color-surface` 底、`--color-border-strong` 1px 边、`--radius-sm`；聚焦时边改为 `--color-focus`，外加 2px 焦点环。
- 占位文字：`--color-text-faint`，不加透明度。
- 黑白三档使用一个分段选择器，每段最小高 44px；选中段用 `--color-accent-soft` 底与 `--color-accent` 字，另外加 1px 当前段边框，不能只换颜色。
- 真正禁用的主要动作：`--color-disabled` 边与图标、说明文字用 `--color-text-faint`。编辑态“置灰但仍可按”的三个文件动作按此画，按下后仍给原因。

### 7.3 正文里的特殊内容

- **声明区**：左边 2px `--color-border`，左侧内边 12px，上下各 4px；字体 `--font-ui` 14px / 1.65，文字 `--color-text-secondary`。不做灰底卡片。
- **标签**：`--color-chip` 底、`--color-text-secondary` 字、13px、22px 高、胶囊圆角。已完成任务里的删除线不穿过标签。
- **勾选框**：18px 看见尺寸，1.5px `--color-border-strong` 边；勾选后 `--color-accent` 底，勾用 `--color-on-accent`。外层 44px 命中区，视觉框保持 vertically centered。
- **行内代码**：`--color-code` 底，左右 4px、上下 2px，`--radius-xs`；代码块同底，内边距 16px，横向滚动。
- **表格**：表头 `--color-surface`，单元格边线 `--color-border`，单元格内边距 8px 12px；整表横向滚动，不压缩到难以阅读。深色下不使用纯白表头。
- **图片**：`max-width: 100%`，`--radius-sm`，加载与透明图衬底 `--color-image-matte`。说明文字 13px、`--color-text-secondary`。
- **暗色图片**：不做反相。正文图片默认 `filter: brightness(.85)`，减少白底截图的眩光；若进入全屏查看则恢复 `brightness(1)`。图片里的文字、代码与颜色关系不能靠反相改变。
- **未知 / 找不到 / 连不上**：未确认位置用 `--color-text-secondary` + 中性边框；确认真找不到用 `--color-danger`；连不上用 `--color-warning`。三者的文字必须同时说清状态，不靠颜色猜。

### 7.4 空状态、弹窗、操作表与提示条

- 空状态主提示 18px 衬线字；最近打开列表在下方 32px。第一次没有记录时仍保留完整提示与适当留白，不显示转圈。
- 最近打开条目名字 15px，父目录 12px；“已失效”用 12px 危险色文字，保留原名与父目录，不整条变红。
- 弹窗标题 18px，正文 15px；标题与内容之间 16px，动作区间隔 8px。窄屏主动作在下，次动作在上或左侧，但两者都至少 44px。
- 操作表动作行 48px；删除单独使用危险色，取消放最后，与危险动作之间留 8px 分隔。
- 提示条严格沿用已定形态：全局居中、离底 80px、32～36px 高、宽上限 80vw、13px 字。普通提示 2.5 秒，带动作 8 秒；不改成侧栏内提示。

## 8. 图标规范与清单

### 8.1 统一画法

- 全部内联自绘 SVG，`viewBox="0 0 24 24"`；默认显示 20px，树图标 18px，顶栏可用 22px。
- 线宽 **1.5px**，`stroke-linecap="round"`、`stroke-linejoin="round"`；不用图标字体、emoji 或外部图标请求。
- 默认 `fill="none"`、`stroke="currentColor"`。只有「更多」的三个点可用实心圆，点半径 1.5px。
- 图形主体留在 2px 安全边距内；水平 / 垂直线尽量落在半像素对齐后的清晰位置。
- 同一个图标只保留一份路径定义，通过 `<use>` 或共享模板复用，不在各组件里各画一版。

### 8.2 本次图标清单

| 名字 | 用途与位置 | 画法要点 |
|---|---|---|
| `sidebar-open` | 打开侧栏；正文左上 | 三条 16px 横线，纵向位置 6 / 12 / 18 |
| `close` | 关闭侧栏、弹窗、气泡 | 两条对角线，端点距边 6px |
| `search` | 搜索框左侧 | 镜片直径约 12px，柄长 4px |
| `settings` | 进入设置 | 中心圆 + 简化齿轮，避免过密细齿 |
| `new-note` | 新建笔记 | 24 网格内一枚加号；命中按钮的无障碍名字为“新建” |
| `back` | 返回目录、退出当前层 | 单一左向折线，不与系统返回箭头混用文字 |
| `more` | 文件操作；正文顶栏 / 宽屏树行 | 三个水平圆点，视觉居中 |
| `chevron-right` | 折叠文件夹 | 12px 显示，线宽 1.5px |
| `chevron-down` | 展开文件夹 | 与上一枚同路径旋转，不另画粗细 |
| `folder` | 文件夹行 | 18px；文件夹选中时颜色随文字 |
| `note` | 笔记行、最近打开 | 18px；折角页，折角不超过 5px |
| `invalid` | 最近打开“已失效” | 圆内一条斜线或感叹号；必须同时有文字 |
| `warning` | 连不上等提醒 | 圆角三角形 + 中心线，不只靠黄色 |
| `error` | 确认不存在、危险失败 | 圆内叉；不用于“还没问到” |
| `success` | 已保存等完成反馈 | 单勾；通常只在停留状态使用，普通提示条可不画 |

### 8.3 一个图标什么时候算画完

同时满足才算完成：

1. 在 18、20、22px 三种实际显示尺寸下都不糊、不偏心，线与端点风格和其他图标一致。
2. 浅色与深色各看一次；图标与背景的非文字对比度至少 3:1。
3. 图标按钮的图形可以只有 20px，但按钮命中区必须至少 44×44px。
4. 有名字：装饰图标对辅助技术隐藏；独立按钮提供明确的无障碍名称。
5. 键盘焦点清晰可见；按下、禁用、当前态都不是只把图标随意调透明度。
6. 不依赖网络、不依赖平台 emoji，离线打开仍完整显示。

## 9. 动效

### 9.1 时长与缓动

| 动作 | 时长 | 缓动 / 属性 |
|---|---:|---|
| 手机侧栏滑入 | 220ms | `cubic-bezier(.2,.8,.2,1)`；只动 `transform` |
| 手机侧栏滑出 | 180ms | `cubic-bezier(.4,0,1,1)`；只动 `transform` |
| 遮罩淡入 | 180ms | `ease-out`；只动 `opacity` |
| 遮罩淡出 | 160ms | `ease-in`；与侧栏一起结束 |
| 树 / 搜索 / 设置内容切换 | 120ms | 新内容 `opacity 0→1`，可带 4px 上移；输入框不动 |
| 按钮 / 行悬停与按下 | 100ms | 背景与文字颜色；不缩放 |
| 普通弹窗出现 | 160ms | `opacity` + 8px 上移；不做弹簧 |
| 操作表升起 | 200ms | `cubic-bezier(.2,.8,.2,1)`；从可见视口底部起 |
| 提示条出现 / 消失 | 120ms | 只动 `opacity`；停留计时不变 |

### 9.2 不动的部分

- 树的 197 行展开 / 收起**直接切换**，不做整段高度动画；长列表动画既慢又抢滚动。
- 宽屏侧栏开合直接切换，或最多 120ms 短过渡；不让正文阅读位置缓慢漂移。
- 正文换篇不淡入整篇文章，避免阅读时每次闪一下。
- 加载不做无限 shimmer；静态说明已经足够。主题切换不做全屏颜色渐变。

### 9.3 减少动态效果

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    scroll-behavior: auto !important;
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
  }
}
```

减少动态效果时，侧栏、弹窗、操作表、提示条立即到位；功能、停留时间与焦点顺序不变。

## 10. 点击、焦点与可读性验收

- 所有独立按钮、树行、搜索结果、最近打开条目、设置选项、弹窗动作都至少 44×44px。文字链接在正文中保留阅读流，但其可点文本不得只靠一个标点。
- 点击区尺寸由元素本身或稳定外层提供，不靠只在某状态下才出现的伪元素撑大。
- 键盘顺序与视觉顺序一致；焦点环不能被侧栏、弹窗或 `overflow` 裁掉。
- 操作表与弹窗打开后焦点进入其中，关闭后回到触发按钮；手机侧栏打开后焦点不落到遮罩后的正文。
- 长按开始就有 `--color-pressed` 视觉反馈；不依赖设备一定支持振动。
- 长段正文、表格、代码块、声明区、标签、勾选框分别在明暗两套下检查；不能只切背景色就报完成。
- 深色正文图片默认降亮度，截图文字仍需真机辨认；若 85% 影响某类技术图，应针对该图提供全屏原亮度查看，而不是把所有图片恢复成刺眼白底。

## 11. 文案语气

1. **先说是哪一件事，再说下一步。** “找不到”“还没问到”“连不上”互不冒充。
2. **直说，不喊口号。** 不写“糟糕”“成功啦”，不写感叹号，不用颜色代替句子。
3. **不确定就说不确定。** 没问到时不显示“已失效”；请求失败时不显示“没有笔记”。

模板：

- 找不到：`这篇不在了，可能被改名或删掉了。`
- 还没问到：`文件名单还在加载…`
- 连不上：`连不上服务端，搜索暂时用不了。恢复联网后再试。`

已经逐字定过的文案继续照 `design-brief.md` 附录 C，不在视觉阶段改写。

| 输入框与未勾选框边界 | `border-strong` |
| 双链、主按钮、当前笔记、选中竖线 | `accent`、`on-accent` |

## 13. 完成定义

视觉落地只有同时满足以下条件才算完成：

- [ ] 所有组件只使用语义颜色；浅色与深色没有遗漏的写死颜色。
- [ ] §2.3 的配对复测仍达标，未通过透明度把文字再次变淡。
- [ ] 深色不是反相；正文、图片、表格、代码、勾选框、标签、声明区逐项看过。
- [ ] 从真正刷新到解锁框出现，深色启动没有任何白帧。
- [ ] 手机正文 17px、输入 16px；没有其他关键文字低于 14px。
- [ ] 宽屏文字行宽上限 720px；侧栏固定 304px；手机侧栏为 75vw。
- [ ] 树行与独立控件命中区至少 44px；选中文件夹与正在读的笔记可同时辨认。
- [ ] 侧栏 220 / 180ms、遮罩 180 / 160ms，减少动态效果时立即到位。
- [ ] 图标通过 §8.3 六项检查，离线仍完整。
- [ ] 搜索、结果刷新、提示条出现都不替换输入框节点；编辑动作区不被键盘遮住。
