搜索收起 / 点滑手感 · 小原型（#57 · 抛弃式）

第一条　点叉 = 清空词，光标和键盘都还在。
第二条　只要动在搜索框之外（点或滑都算）：框空 → 收成放大镜；框有词 → 只取消输入状态，框仍显示、词仍在。
第三条　叠在第二条上面：如果是点击且点到了能点的东西，就照常触发它；如果是滑动，不管滑在哪里，都取消输入状态 + 照常滚动列表。
模拟键盘上的点／滑都不算「框外」（按「输入法键盘除外」）；点叉、点搜索框里也不算。
上一版做错、这一版改回来了：框空时滑动也会收成放大镜；点可点物时，除了触发它，搜索框该收还是收、该留还是留。请重点试第 7、13、14 条。
真机请特别看两处：① 正在打拼音时去滑列表，框里会不会留半截拼音；② 键盘弹起时，底部「新建／设置」横条被盖住了，这一版没有答案，归后面的界面验收定。
