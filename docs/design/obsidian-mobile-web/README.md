## 三条前瞻约束

设计从一开始就被三条约束钉住，它们解释了很多看起来「过度设计」的地方：

1. **大陆免梯子直连** —— 决定了平台选型（`spec.md` §9），也决定了「必须有一个服务端」这一架构前提（Gitee 不返回 CORS 头，token 不能进浏览器）。
2. **未来开源 / 多用户** —— 决定了鉴权层被抽象成可插拔模块；owner/repo 固定在后端，前端请求不携带；token 永不进浏览器。
3. **未来可打包为 App** —— 决定了前端选 Vite + 原生 JS（无框架、体量小），以及页面结构简单到可以直接塞进 WebView。

## 明确不在范围内

反向链接面板、标签图、嵌入 `![[...]]`、callout、任务勾选、多仓库切换、分支选择、App 打包本身。完整清单见 [`map.md`](map.md) 的 Out of scope 一节与 `spec.md` §1。
